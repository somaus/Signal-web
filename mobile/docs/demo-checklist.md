# 시연 체크리스트

이슈 #107(시연 준비 및 마무리)의 확인 항목입니다. 앱 코드로 처리한 것은 체크해 두었고, 사람이 직접 해야 하는 것은 비워 두었습니다.

## 코드로 처리한 것

- [x] 앱 아이콘과 스플래시를 Signal 아이콘으로 교체
- [x] 화면을 그리다 오류가 나면 앱이 꺼지지 않고 "다시 시도" 화면 표시
- [x] 더보기 화면에서 내 정보를 불러오는 동안 안내 문구 표시
- [x] Expo Go를 쓸 수 없을 때를 위한 EAS preview APK 빌드 설정
- [x] 실행 방식 확정(Expo Go 기본, APK 대체): [README](../README.md#시연-실행-방식)

## 시연 전날

- [ ] 배포 서버(`https://signal.https.gsmsv.site`)가 살아 있는지 확인: 휴대폰 브라우저로 접속해 응답이 오는지 본다
- [ ] 시연용 휴대폰에 Expo Go 설치, `npx expo start`로 QR 실행이 되는지 확인
- [ ] 시연 기기가 Android이고 Expo Go가 안 되면 `eas build --profile preview --platform android`로 APK를 미리 만들어 설치
- [ ] 시연용 계정으로 로그인이 되는지 확인(비밀번호는 문서에 적지 않는다)
- [ ] 샘플 이미지를 휴대폰 앨범에 넣어 둔다: 위험 메시지 캡처 1장, 딥페이크 의심 얼굴 사진 1장, 얼굴이 없는 사진 1장(실패 사례)
- [ ] 시연 기기 언어를 한국어로 맞춘다

## 리허설

- [ ] 실기기 리허설 1회차: 시나리오를 처음부터 끝까지 한 번 돌리고 막힌 곳을 적는다
- [ ] 실기기 리허설 2회차: 고친 뒤 다시 돌려 소요 시간을 잰다
- [ ] 와이파이를 끄고 켜는 상황(네트워크 오류 안내가 뜨는지)을 한 번 확인한다

## 시연 시나리오(초안, 팀에서 확정)

1. 앱 실행: 스플래시 → 홈
2. 위험도 분석: 의심스러운 메시지 캡처를 올리고 결과(점수, 위험 신호)를 보여준다
3. 딥페이크 탐지: 사진을 올리고 판정 결과를 보여준다
4. 실패 사례: 얼굴이 없는 사진을 올려 "얼굴을 찾지 못했어요" 안내를 보여준다
5. 더보기: 언어 변경, 로그인 상태 확인

분석·탐지 화면은 #101, #103 브랜치가 합쳐진 뒤에 시연할 수 있습니다. 확정되면 순서와 말할 내용을 이 문서에 적어 둡니다.

## 대체 자료(시연 중 네트워크나 서버가 말썽일 때)

- [ ] 시나리오 전체 화면 녹화 영상(휴대폰 화면 녹화)을 발표 PC와 휴대폰 양쪽에 저장
- [ ] 발표용 화면 캡처: 분석 결과, 탐지 결과, 실패 안내
- [ ] 서버가 응답하지 않을 때 영상으로 바로 넘어가는 순서를 팀원과 정해 둔다
